# MOJ Arbitrary Coord Loader（MOJ 任意座標変換ローダー）

法務局備付地図データ（任意座標系 ZIP/XMLファイル）を読み込み、
GCPを用いてヘルマート変換またはアフィン変換で平面直角座標系へ変換し、
QGISプロジェクトにポリゴンレイヤとして追加するプラグインです。

## 対応QGIS バージョン

- QGIS 3.16 以上

## 特徴

- **任意座標系専用**: `<座標系>任意座標系</座標系>` を持つXMLファイルのみを対象
- **日本測量座標対応**: XMLのX（縦方向）とY（横方向）を自動的にswapして正しい図形を表示
- **GUI上プレビュー**: 任意座標データをGUI内キャンバスでプレビュー（QGIS地図上には表示しない）
- **地番検索**: 大字・小字・地番のプルダウンで目的の図郭を絞り込み
- **複数地番選択**: 複数の地番を同時に選択して同一図郭内を一括表示
- **クリックGCP選択**: プレビューキャンバス上の筆界点をクリックしてGCP登録
- **自動変換方式選択**:
  - GCP 2点 → ヘルマート変換（4パラメータ相似変換）
  - GCP 3点以上 → アフィン変換（6パラメータ最小二乗）
- **残差RMSE表示**: 変換精度を数値で確認可能
- **地番ラベル表示**: 変換後レイヤに地番ラベルを自動付与

## インストール方法

1. このフォルダ全体を QGIS のプラグインフォルダに配置してください
   - Windows: `%APPDATA%\QGIS\QGIS3\profiles\default\python\plugins\`
   - Linux: `~/.local/share/QGIS/QGIS3/profiles/default/python/plugins/`
   - macOS: `~/Library/Application Support/QGIS/QGIS3/profiles/default/python/plugins/`
2. QGISを起動し、「プラグイン」→「プラグインの管理とインストール」→「インストール済み」から
   「MOJ 任意座標変換 Loader」を有効化

> **セキュリティに関する任意推奨**  
> `defusedxml` をインストールすると、XML解析時の安全性がさらに高まります（インストール済みの場合は自動的に使用されます）。  
> QGIS Python コンソール（プラグイン → Python コンソール）で以下を実行してください。必須ではありません。  
> ```
> import pip; pip.main(['install', 'defusedxml'])
> ```

## 使い方

### Step 1: データ読み込み・図形確認

1. ツールバーのアイコン（または「ベクタ」メニュー）からプラグインを起動
2. 「参照...」ボタンで法務局地図データのZIPまたはXMLファイルを選択
3. 任意座標系でない場合は自動的にエラーが表示されます
4. 大字・小字をプルダウンで選択し、地番リストから対象地番を1件以上選択（複数可）
5. 「図郭確定・ポリゴン表示」ボタンをクリック
6. プレビューキャンバスに筆ポリゴンが表示されます
   - 金色のポリゴン: 選択した地番
   - 青色の点: 筆界点（クリックでGCP選択）

### Step 2: GCP入力・座標変換・レイヤ追加

1. プレビューキャンバス上の筆界点（青い点）をクリックしてGCPとして登録
2. 「② GCP入力」タブのテーブルで、登録した点の「平面直角X(m)」「平面直角Y(m)」を入力
3. 変換方式を選択（推奨: 自動選択）
4. 出力CRSのEPSGコードを入力（例: JGD2011 III系=6671, VII系=6675）
5. 「座標変換を実行」ボタンをクリックして変換パラメータを確認
6. 「QGISレイヤに追加」ボタンでQGISプロジェクトにレイヤを追加

GCP入力のコツ

- GCPは対象地域内にできるだけ分散して配置する
- 既知点として筆界確認書や地積測量図の測点座標が利用可能
- 残差が1m以上のGCPは入力値を再確認する
- 縮尺が混在する場合はアフィン変換を選択する

## 座標変換の仕組み

### ヘルマート変換（4パラメータ相似変換）
```
X = a*x - b*y + tx
Y = b*x + a*y + ty
```
- a = s×cos(θ), b = s×sin(θ)
- s: 縮尺係数, θ: 回転角度
- tx, ty: 並進量

### アフィン変換（6パラメータ）
```
X = a1*x + a2*y + a3
Y = b1*x + b2*y + b3
```
- 最小二乗法で6パラメータを決定

## 注意事項

- 任意座標系のXMLは（0,0）や（100,100）等を原点としており、
  変換なしではQGIS地図上の正しい位置に表示されません。
  本プラグインではGUI内プレビューのみで確認後、座標変換してから追加します
- GCPは現地測量や他の資料から平面直角座標値を取得してください
- 精度の高い変換のためには分散した3点以上のGCPを推奨します
